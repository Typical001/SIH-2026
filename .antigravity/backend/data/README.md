# Demo coastline data

`ne_10m_land.zip`: Natural Earth 1:10 million land polygons, version 5.1.1.
Downloaded 2026-09-25 from https://naturalearth.s3.amazonaws.com/10m_physical/ne_10m_land.zip

SHA-256: `e547d749445eaa0964aba76738090ec88f5e63c4585122170f98c67a7ea922dc`

Source: https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/
Terms: https://www.naturalearthdata.com/about/terms-of-use/ (public domain).

Used locally for demo land/segment intersection checks; no runtime download.
The scale is 1:10 million, **not 10-metre resolution**. This is generalized
geography, not a hydrographic chart; source documents limitations near southern
Chile. Ocean approach points are illustrative, not surveyed port approaches.
Simulated iceberg and environmental datasets are separate from this coastline.
